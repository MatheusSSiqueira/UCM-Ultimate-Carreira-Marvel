# Imagens dos painéis

Adicione as imagens locais com os nomes `painel-01.jpg` até `painel-12.jpg` nesta pasta. O mosaico pode reutilizar esses arquivos para preencher os painéis.

Prefira proporções de **4:3** para painéis horizontais e **3:4** para painéis verticais. Cada arquivo deve ter no máximo **150 KB**.

Use somente arte própria, licenciada para esse uso ou em domínio público. Não inclua quadrinhos, personagens, logotipos ou outras imagens protegidas por direitos autorais sem autorização. Na ausência das imagens, o site apresenta ilustrações de cena de ação geradas por CSS.
